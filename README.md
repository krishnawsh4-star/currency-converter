# Currency Converter

A simple and responsive currency converter built using HTML, CSS, and JavaScript.

## Features

- Convert between multiple currencies
- Uses a real-time currency exchange API
- Fetches exchange rates dynamically
- Simple and clean user interface
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API
- Frankfurter API

## How It Works

Enter an amount, select the source currency and the target currency, and click the **Get Exchanged Value** button.

The application fetches the latest available exchange rate from the API and calculates the converted amount.
